# Saving and reusing Copilot prompts

Companion to [Stringfest Analytics: How to save and reuse prompts for Copilot in Excel](https://stringfestanalytics.com/how-to-save-and-reuse-prompts-for-copilot-in-excel/).

Open `prompts.md` for the fictional worked example and reusable version. Copy only the prompt inside the relevant code block.

1. Run the fictional example in Microsoft 365 Copilot Chat. It includes all its data, so no workbook is required.
2. Check the answer: Actual $44,000; Budget $47,000; variance -$3,000; overall variance -6.38%. The region order should be East, North, West, South.
3. Save the successful prompt with a useful title, such as "Revenue review - variance check".
4. On reuse, replace the example data or fill every bracketed field in the reusable version. In Excel, explicitly name the current worksheet and table. In Copilot Chat, attach or select the current file, or paste the data. Saving a prompt does not attach the next workbook automatically.
5. Review the source, arithmetic and commentary each time.

The example uses invented figures. No macros, scripts, scheduled tasks or add-ins are included.
